How binary search works
  1. The problem: a college has thousands of students, each with a roll number. Looking up one specific roll number in a sorted list by checking every record (linear search) is slow and does not scale.
  2. Binary search solves this by looking at the middle roll number of the current window [low … high].
  3. If it equals the target roll number, return its index. If it is greater, the target can only be to the left; if smaller, only to the right — the list is sorted, so an entire half becomes impossible at once.
  4. Discard the impossible half and repeat on the survivor: each call solves a problem of size n/2 plus O(1) work.
  5. That is the divide-and-conquer recurrence T(n) = T(n/2) + O(1) = O(log n) — a college of a million roll numbers would need at most 20 probes.
